## MediTrack — Clinic & Appointment Management System


**Overview**


MediTrack is a Clinic & Appointment Management System developed as an academic assignment. The project aims to simplify the management of clinics by providing an organized platform for handling appointments, patient records, and doctor information.

## Features

- Add and manage doctors
- Add and manage patients
- Schedule appointments
- Search doctors and patients
- Generate bills
- Observer-based appointment notifications
- Strategy-based billing
- Stream API analytics
- Deep vs. shallow cloning demonstration
- Menu-driven console interface

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Build the project using Maven.
4. Run `Main.java`.
5. Use the console menu to interact with the application.

## Notes

- This project stores all data in memory.
- No external database is used.
